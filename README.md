## Опис проєкту

Проєкт присвячений створенню спеціалізованого AI-агента для автоматизації основних етапів розробки програмного забезпечення мовою C++.

Агент координує створення структури застосунку, налаштування системи складання, підготовку модульних тестів та конфігурацію безперервної інтеграції.

Особлива увага приділяється перевірці результатів генерації, безпечній роботі з файлами та можливості повторного виконання команд.

## Технології

- C++ — реалізація програмного застосунку.
- CMake — конфігурація та складання.
- GoogleTest / CTest — модульне тестування.
- GitHub Copilot — створення та виконання інструкцій AI-агента.
- GitHub Actions — автоматизована перевірка на Windows, Linux і macOS.
- Git — контроль версій.

## Архітектура AI-агента

Агент використовуватиме три основні навички:

1. `project-scaffold` — створення структури C++ проєкту.
2. `build-and-test` — налаштування складання та тестування.
3. `github-actions` — підготовка CI workflow.

Команда `/init` координуватиме послідовне виконання операцій, а `/check` перевірятиме отримані результати.

## Запуск

Після реалізації агента повний сценарій створення проєкту запускатиметься через GitHub Copilot Chat у VS Code командою:

`/init`

Для перевірки результатів використовуватиметься:

`/check`

Детальні інструкції щодо локального складання та запуску застосунку будуть наведені у `docs/usage.md`.
